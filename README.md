# 🚀 Dinamik Portfolyo Uygulaması

Bu proje, ASP.NET Core MVC kullanılarak geliştirilmiş dinamik bir kişisel portfolyo uygulamasıdır. Uygulama; ziyaretçilerin portfolyo içeriklerini görüntüleyebildiği kullanıcı arayüzü ve tüm içeriklerin yönetilebildiği admin panelinden oluşmaktadır.

Admin paneli üzerinden yapılan tüm işlemler anlık olarak kullanıcı arayüzüne yansımaktadır.

---

# 📌 Proje Özellikleri

- Dinamik portfolyo sayfası
- Yönetilebilir admin paneli
- Dashboard ekranı
- İletişim formu
- Kullanıcı mesajlarının yönetimi
- Otomatik okundu bilgisi
- Giriş ve çıkış işlemleri
- Yetkilendirme (Cookie Authentication)
- Responsive tasarım

---

# 📩 İletişim

Kullanıcılar iletişim formu aracılığıyla mesaj gönderebilir.

Gönderilen mesajlar admin panelinde görüntülenebilir ve yönetilebilir. Mesaj detayına girildiğinde ilgili mesaj otomatik olarak **okundu** durumuna geçirilir.

# 🚀 Kurulum

1. Projeyi klonlayın.

```bash
git clone https://github.com/kullaniciadi/Portfolio.git
```

2. Veritabanı bağlantısını **appsettings.json** dosyasından düzenleyin.

3. Migration'ları uygulayın.

```bash
Update-Database
```

4. Projeyi çalıştırın.
